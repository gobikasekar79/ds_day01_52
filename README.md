# Construction Cost Variance Analysis

## Project Overview

This project analyzes construction project cost overruns using planned and actual labour and material costs, along with project size, location, duration, equipment cost and subcontracting cost.

The objective is to identify major sources of cost variance, compare projects across different sizes and locations, analyze the relationship between project duration and cost overruns, and build a Linear Regression model for cost variance prediction.

## Dataset

The dataset contains 150 construction projects.

### Features

- Project_ID
- Project_Size
- Location
- Duration
- Planned_Labour_Cost
- Actual_Labour_Cost
- Planned_Material_Cost
- Actual_Material_Cost
- Equipment_Cost
- Subcontracting_Cost

## Technologies Used

- Pandas
- NumPy

## Data Analysis

The analysis includes:

1. Data cleaning and validation
2. Descriptive statistics
3. Labour cost variance calculation
4. Material cost variance calculation
5. Total cost variance analysis
6. Project size comparison
7. Location comparison
8. Duration and cost variance analysis
9. Recurring cost pattern analysis
10. Cost variance visualizations

## Machine Learning

### Algorithm

Linear Regression

### Target Variable

Total Cost Variance

### Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Expected Outcome

The analysis identifies major cost-overrun sources and provides practical recommendations for controlling construction project costs.
